💡 新手必读 · 4 个核心概念 + Token 计费原理

在开始之前，先理解这 4 个概念，你就能看懂全文。它们由浅入深，层层递进：

① 大模型 (LLM)
人工智能的"大脑"。如 GPT-5.4、Claude Opus 4.7、DeepSeek V4，是一切 AI 应用的底层引擎。
② AI 工具
大模型的"外壳"。如 Cursor、Claude Code 是给人用的产品界面，把大模型能力包装成易用应用。
③ Agent（智能体）
能自主完成任务的 AI。给目标，它能自己"思考-行动-反馈"循环，自动调用工具完成复杂任务。
④ Skill / MCP
AI 的"特长插件"。让 AI 能处理 PDF、操作浏览器、查数据库等具体能力。MCP 是 Anthropic 定的统一协议。

💰 Token 是什么？ Token 是大模型处理文本的最小单位。1 个汉字 ≈ 2 Token，1 个英文单词 ≈ 1.3 Token。模型按"输入 + 输出"的 Token 总量计费。例如：1M Token ≈ 50 万汉字 ≈ 一本中长篇小说的内容量。输出 Token 通常比输入贵 3~5 倍。
